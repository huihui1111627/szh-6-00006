# 区域电网黑启动推演台

大面积停电后逐步恢复区域电网的交互式推演系统：连续展示电站、线路、变电节点的带电状态、频率变化与负荷缺口，每一步操作都必须先通过系统校核、再经历频率/潮流的波动稳定过程才生效；错误顺序会触发频率越界、低频减载、线路过载跳闸甚至已恢复区域再次掉电，失败现场保留并可回退；多个恢复策略可同时对照总耗时、风险与未恢复范围，刷新/重启后自动接续原有步骤。

## 运行

纯静态站点，无需构建。任选一种方式：

```bash
# 方式一：直接双击打开 index.html

# 方式二：本地静态服务器（推荐，避免个别浏览器本地文件限制）
python3 -m http.server 8000
# 浏览器访问 http://localhost:8000
```

## 功能与玩法

- **四类操作**：启动电源（黑启动水电/燃机、为火电送厂用电）、接入线路（充电/合环）、合并分区（同期并列）、分批恢复负荷（10/20/30/50 MW 批次）。
- **先校核后生效**：每次操作先给出系统校核结论（允许 / 有风险 / 驳回原因），生效后播放本步暂态，等待频率与潮流稳定。
- **动态过程**：聚合摇摆方程（惯性、调差、负荷阻尼、机组爬坡）+ 直流潮流（控制区经济调度、联络线交换功率），频率曲线实时绘制。
- **保护动作**：低频减载 49.0Hz、频率崩溃 48.5Hz；线路持续过载（>100% 持续 8s）或严重过载（≥125% 瞬时）跳闸。
- **失败与回退**：失败后冻结现场并闭锁新操作，可回退到任意一步之前重排恢复顺序。
- **多策略对照**：新建 / 分叉复制策略，并排比较步数、总耗时、风险积分、负荷恢复率、未恢复 MW、带电范围。
- **断点续演**：所有策略与完整步骤现场保存在 `localStorage`，重启自动接续当前策略。

## 参考恢复路径

1. 西：白水河水电（黑启动）→ 西郊变 → 城西负荷（10–20MW 小批起步）→ 中心变；
2. 东：云台山燃机（黑启动）→ 东湖变 → 城东负荷（小批）；
3. 频差 ≤0.20Hz 时并列中心—东湖，合并两分区；
4. 中心→北站→北岭火电，启动大电源后恢复中心城区；
5. 打通西郊—南岭—南港—东港通道，启动东港火电；恢复临港工业区与城北；
6. 东部负荷密集时，东西间仅靠单回联络线会过载，需提前合上北站—东湖第二通道分流。

## 典型失败陷阱

- 孤网首批负荷过大 → 频率跌破 49.0Hz，低频减载切负荷，策略失败；
- 两侧频差 >0.20Hz 强行并列 → 同期校核直接驳回；
- 火电未获得外部厂用电源就启动 → 驳回；
- 功率大量经单回联络线外送 → 持续过载 8s 跳闸，可能解列或使已恢复区域再次掉电。

## 代码结构

- `index.html` / `css/style.css` — 页面与调度中心风格样式；
- `js/data.js` — 电网场景（4 电站 / 8 变电站 / 5 负荷 / 20 线路）与稳定保护定值；
- `js/engine.js` — 仿真引擎：拓扑带电分析、直流潮流、频率动态、保护动作、操作校核；
- `js/store.js` — 多策略 `localStorage` 持久化；
- `js/chart.js` — 频率波动曲线（安全/告警/越限色带）；
- `js/app.js` — SVG 电网渲染、操作面板、暂态回放循环、步骤与回退、策略对照。
